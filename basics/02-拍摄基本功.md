# 02 · 拍摄基本功

> 目标：掌握稳定拍摄、曝光控制、专业模式参数这三项基本功。练熟之后，出片率会有肉眼可见的提升。

## 1. 先把照片拍"稳"

糊片是新手最大的敌人。手机暗光下快门会变慢，手抖就糊。

**持机姿势：**

- 双手持机，手肘夹紧身体，形成"三脚架"结构
- 按快门前**屏住呼吸半秒**，按完不要立刻放下手机（快门可能有延迟）
- 能倚靠就倚靠：栏杆、桌面、墙面都是免费三脚架

**防糊检查清单：**

- [ ] 镜头擦干净了吗？（口袋里的指纹是画质杀手，先擦再拍）
- [ ] 光线够吗？暗光下手机会拉高 ISO，又糊又噪
- [ ] 主体在动吗？动的主体用连拍，拍完挑一张

## 2. 构图前先做"减法"

新手和高手照片最大的差别，往往不是技术，而是**画面里有没有多余的东西**。

按下快门前问自己三个问题：

1. 主体是谁？一眼能不能看出？
2. 画面里有没有抢戏的东西（地平线歪了、路人半个身子、垃圾桶入镜）？
3. 边缘有没有被裁切得难受的东西（半个人头、半个招牌）？

**两个立刻见效的动作：**

- **蹲下来或举起来**：换视角，别永远站着平拍。低角度拍显得主体高大，高角度俯拍适合餐桌美食
- **走近两步**：拍不满就走近，而不是拉变焦。焦距拉太长画质掉得快

## 3. 曝光的"点、滑、锁"三板斧

第 01 篇讲过原理，这里练成肌肉记忆：

1. **点**：点击主体对焦测光
2. **滑**：滑动 EV 小太阳微调明暗，**宁欠勿过**（欠一点后期拉得回来，过曝的白色救不回来）
3. **锁**：长按锁定 AF/AE，再从容构图

**典型场景：**

- 逆光人像：对人脸点按，EV +0.3~+0.7 提亮脸部
- 雪地/白墙（拍出来发灰）：EV +0.7~+1.0，让白色真的白
- 夜景灯光：EV -0.3~-1.0，压住高光，保留灯的细节和色彩

## 4. 专业模式入门（想进阶再看）

专业模式把手机当成可调参数的相机，核心就 4 个参数：

| 参数 | 作用 | 新手建议 |
|---|---|---|
| ISO（感光度） | 对光的敏感度 | 越低画质越好。白天 50~100，夜晚尽量不超过 800 |
| S（快门速度） | 曝光时间 | 拍静态 1/60s 以上；拍流水丝滑用 1/4s~2s（必须三脚架）；抓拍用 1/500s+ |
| WB（白平衡） | 色调冷暖 | 自动即可；想要氛围可手动：阴天调暖（5500K+），夜灯场景调冷 |
| MF（手动对焦） | 手动控制焦点 | 拍微距、隔玻璃拍摄时用，避免对焦拉风箱 |

**曝光的平衡公式：** 明亮度 ≈ ISO × 快门时间。ISO 降低，快门就要变慢，反之亦然——两个一起调，直到 EV 归零。

**专业模式最值得玩的一件事：** 找个小溪，三脚架固定，快门 1s、ISO 50，拍出丝滑流水的长曝光效果。

## 5. 什么时候用什么工具

| 场景 | 推荐做法 |
|---|---|
| 白天拍人/拍景 | 普通模式 + 构图 + EV 微调 |
| 夜景/暗光 | 夜景模式，手持稳住；能倚靠就倚靠 |
| 背景杂乱的人像 | 人像模式虚化 |
| 抓拍运动/孩子 | 连拍模式，快门优先级最高 |
| 流水/车轨/星空 | 三脚架 + 专业模式长曝光 |

## 6. 轻量配件（可选）

预算有限时按优先级买：

1. **手机三脚架 + 夹子**（几十元）：夜景、长曝光、视频稳定全靠它
2. **小补光灯**：拍人像、美食补光，比后期提亮自然得多
3. 外接镜头（广角/微距）：玩法性质，优先级最低

## 课后练习

1. 用"点、滑、锁"流程拍 10 张，每张先点主体、再调 EV，对比默认直出的差别
2. 同一场景分别拍"站姿平拍"和"蹲姿低角度"，体会视角对气势的影响
3. 找一个杂乱的桌面，只保留一个主体拍一张"干净"的照片
4. （进阶）借或买三脚架，用专业模式拍一张 1 秒长曝光的流水或车轨
