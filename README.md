# Open Photo · 摄影学习

一个用于记录、整理和分享摄影学习过程的仓库。

## 关于

本仓库聚焦摄影学习的方方面面，涵盖从基础理论到实战技巧的完整路径。

## 内容

- **基础理论**：构图、光线、色彩、曝光
- **器材知识**：相机、镜头、附件的选择与使用
- **拍摄技巧**：人像、风光、街拍、静物等题材
- **后期处理**：修图思路与常用工具
- **作品复盘**：拍摄心得与案例分析

## 目录结构

```
open-photo/
├── README.md
├── basics/          # 摄影基础
├── techniques/      # 拍摄技巧
├── post-processing/ # 后期处理
└── works/           # 作品与复盘
```
