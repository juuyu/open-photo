# Open Photo · 摄影学习

一个用于记录、整理和分享摄影学习过程的仓库。

## 关于

本仓库聚焦摄影学习的方方面面，涵盖从基础理论到实战技巧的完整路径。

## 内容

- **基础理论**：构图、光线、色彩、曝光
- **器材知识**：相机、镜头、附件的选择与使用
- **拍摄技巧**：人像、风光、街拍、静物等题材
- **后期处理**：修图思路与常用工具
- **作品复盘**：拍摄心得与案例分析

## 手机摄影学习路径（渐进式）

按顺序学，每篇末尾有练习；练完一篇再下一篇，效果最好。
