# 06 · 视频拍摄

> 目标：用手机拍出"稳、平、有内容"的视频。新手期不追求炫技运镜，先把基本功做对。

## 1. 拍摄设置（一次设好）

| 项目 | 建议 | 原因 |
|---|---|---|
| 分辨率 | 4K 30fps（日常）/ 1080p 60fps（要慢动作的素材） | 4K 留裁剪空间；60fps 后期可放慢 2 倍 |
| 帧率 | 日常 30fps，运动/宠物用 60fps | 全片混用帧率观感不统一 |
| 网格线 | 开 | 水平是视频的生命线 |
| 变焦 | 固定一颗镜头拍完一个镜头 | 视频中数码变焦/镜头切换非常明显 |

**原则：拍照可以自由发挥，视频先求"稳和稳"。**

## 2. 新手三大基本功

### 2.1 稳

- 双手夹肘持机，脚步小碎步移动（"忍者步"：膝盖微屈当减震）
- 能上稳定器就上，没有就靠：三脚架、桌面、身体倚靠
- 镜头运动要**慢到感觉无聊**——回放时才发现刚好

### 2.2 平

- 开网格线，让地平线/建筑竖线对齐
- 移动时保持手机高度不变（想象端着一碗水）

### 2.3 动

静止画面 5 秒以上观众就划走了。每个镜头里要有"一个动作"：

- 主体动：人走过来、咖啡倒进杯子
- 镜头动：轻微推近、横移、升降
- 都不动：那就改场景

## 3. 够用的运镜就五种

| 运镜 | 怎么做 | 用途 |
|---|---|---|
| 推/拉 | 镜头缓慢向前/向后 | 开场强调主体、结尾收束 |
| 摇 | 原地左右转动 | 展示环境全景 |
| 移 | 横向平移跟随 | 跟拍行走，最常用、最出效果 |
| 升降 | 从低到高/高到低 | 揭示场景，配台阶、电梯很好用 |
| 环绕 | 绕主体走半圈 | 强调主体，需要开阔空间 |

**新手组合公式：** 低角度起步 → 越过前景（树叶/栏杆）→ 升到主体 → 缓慢横移。一组镜头拍 10 秒，剪辑用 3 秒。

## 4. 镜头语言：景别要有变化

成片好看的秘密是**景别跳跃**：远景交代环境 → 中景交代动作 → 特写交代细节/情绪。

拍一个事件（比如做咖啡）至少拍齐：

- 1 个定场镜头（全景 3~5 秒）
- 3~5 个过程镜头（中景：手部动作）
- 3 个特写（蒸汽、液面、成品）

**每个镜头拍 8~10 秒**，剪辑时只用中间最稳的 2~4 秒。

## 5. 声音：被新手忽略的一半

- 观众可以容忍画面一般，无法容忍声音难受
- **离得近，声音就好**：采访/说话时手机离人 1 米内
- 环境噪音大时录一段"室内环境音"备用，剪辑时垫底
- BGM 选无人声的轻音乐，音量压到人声的 20%~30%

## 6. 剪辑入门（剪映/CapCut）

最小可用流程：

1. **粗剪**：删掉废镜头，每段留 2~4 秒
2. **排序**：定场 → 过程 → 特写，景别交替，避免同景别连续 3 个
3. **卡点**：动作/转场对齐音乐节拍（剪映"踩点"功能）
4. **转场**：90% 的情况直接硬切最好看；叠化用于时间流逝
5. **调色**：套一个滤镜统一全片色调，强度 50% 左右
6. **字幕**：口播必须配字幕，安静场景可不加
7. 导出：1080p 或 4K，30fps

## 7. 常见问题自查

- [ ] 画面抖成帕金森 → 上稳定器/倚靠/忍者步
- [ ] 全片一个焦距一个角度 → 补拍特写和全景
- [ ] 来回推拉变焦 → 删掉，固定焦距重新拍
- [ ] 横竖屏混乱 → 先确定发布平台：横屏 B 站/视频号，竖屏抖音/小红书
- [ ] 人声忽大忽小 → 靠近录 + 剪映音量曲线统一

## 课后练习

1. 拍"我的一天"60 秒短片：定场 1 个 + 过程 5 个 + 特写 3 个，按第 6 节流程剪出来
2. 只用一个移镜头跟拍朋友走路 10 秒，练忍者步的稳
3. 把同一段素材分别用硬切和叠化剪，对比观感
