# 04 · 用光

> 目标：看懂光线的方向、质地、颜色，学会挑时间和位置。摄影是光的艺术——**选对光，胜过一切修图**。

## 1. 看懂光的三个维度

### 1.1 方向：光从哪边来

| 方向 | 特点 | 用法 |
|---|---|---|
| 顺光（光在你身后） | 主体亮、颜色饱和，但平淡没立体感 | 拍美食、证件照式记录 |
| 侧光（光从侧面来） | 明暗分明，质感立体 | 人像、静物、建筑——**最值得用的光** |
| 逆光（光对着镜头） | 剪影、轮廓光、通透感 | 日落人像、树叶、情绪片 |
| 顶光（正午头顶） | 眼下鼻下难看阴影 | 尽量避开，或让人抬头/找阴影 |

**逆光实操（新手最容易出大片的场景）：**

1. 让光源（太阳/窗）在主体**斜后方**，不要正对镜头直射
2. 对人脸点按对焦，EV +0.5 左右提亮面部
3. 躲开阳光直射镜头（换个角度用身体挡），避免眩光糊一片
4. 想要剪影：反过来 EV -1.5 左右，让主体变成黑色轮廓

### 1.2 质地：硬光还是柔光

- **硬光**：晴天正午、裸灯泡。影子边缘锐利，反差大，适合表达力量感、线条
- **柔光**：阴天、清晨傍晚、窗边不直射的光、阴影里。影调过渡细腻，**拍人像首选**

**柔化光线的免费手段：** 站到阴影边缘（房檐下、树荫里、窗边一米内）——脸朝向亮处，光立刻变柔。

### 1.3 颜色：色温

- 日出日落偏暖（金橙色），阴影和阴天偏冷（蓝），白炽灯偏黄，荧光灯偏绿
- 手机的自动白平衡会"纠正"这些颜色——**纠正了氛围就没了**
- 想保留氛围：专业模式手动锁定 WB，或后期把色温调回暖/冷（见第 07 篇）

## 2. 一天中什么时候光线最好

| 时段 | 光线特点 | 适合拍 |
|---|---|---|
| 黄金时刻：日出后/日落前 1 小时 | 低角度暖光、影子长、天空有色彩 | 人像、风光、街拍（**出片率最高**） |
| 蓝调时刻：日落后 20~40 分钟 | 天空深蓝、城市灯光亮起 | 城市夜景、建筑 |
| 正午 | 顶光硬光、反差大 | 避开；或拍建筑线条、室内、树荫 |
| 阴天 | 巨大的柔光箱 | 人像、花卉、街拍纪实，颜色柔和 |
| 夜晚 | 人造光源 | 夜景模式、霓虹、光轨 |

**结论：想快速提升，就把拍摄安排在黄金时刻。** 同一个人同一个地方，中午拍和日落前拍，差距立现。

## 3. 室内与窗光

窗光是免费的影棚灯：

1. 让人脸**侧对 45° 朝向窗户**：立体感最好
2. 离窗 0.5~1.5 米，光最柔
3. 背景选暗的（关掉的另一侧房间、深色墙），主体亮背景暗，人自动被"打光"
4. 夜晚室内：打开所有灯 + 用补光灯/白纸反光，别只靠头顶吸顶灯

## 4. 夜晚怎么拍

- **先找光再找主体**：夜景摄影本质是"拍摄光源照到的东西"。霓虹灯下、橱窗前、路灯旁都是天然摄影棚
- 主体站到光源**侧面 45°**，脸有一半亮一半暗，氛围感立刻出来
- 用夜景模式手持 2~5 秒稳住；有倚靠更佳
- 灯光过曝时 EV -0.3~-1.0 压高光
- 雨后路面反光、玻璃倒影，都是夜景的加分项

## 5. 常见用光问题自查

- [ ] 正午站太阳底下拍人，脸上全是死黑阴影 → 挪到阴影边
- [ ] 逆光拍人整张脸黑 → 点脸测光 + EV 提亮，或换斜逆光
- [ ] 夜晚开闪光灯拍人，脸油白背景全黑 → 关闪光，找环境光，或用补光灯
- [ ] 灯光下照片整体发黄发绿 → 后期校色温
- [ ] 天空死白/死灰 → 避开正午，等黄金时刻；或后期压高光加色

## 课后练习

1. 同一个人分别在正午和黄金时刻各拍一组，对比差距
2. 拍一张侧光人像（窗边 45°）和一张顺光人像，感受立体感差异
3. 日落时拍一张剪影：主体轮廓清晰、EV 压暗
4. 晚上找一个霓虹/橱窗光源，让人站在光的侧面拍一张
