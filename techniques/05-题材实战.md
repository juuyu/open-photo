# 05 · 题材实战

> 目标：把前四篇的方法落到具体题材。每个题材给一条"固定流程"，照着做就能及格，再慢慢加入自己的理解。

## 1. 人像

**核心思路：脸要亮、背景要净、光线要柔。**

固定流程：

1. **焦段**：主摄或 2x 长焦。超广角贴脸拍会变形，别用
2. **光位**：窗边 45° 侧光 / 黄金时刻逆光或侧光 / 阴影边缘柔光
3. **机位**：镜头略高于对方视线（微俯拍显脸小、显眼睛大）；蹲下平拍儿童
4. **对焦**：点眼睛。半身照眼睛放上三分线
5. **构图**：头顶留少量空间；切位在大腿/腰之间，不切关节
6. **互动**：连拍抓走路、回头、大笑的瞬间，比摆拍自然 10 倍

背景太乱时三选一：换角度避开 / 人像模式虚化 / 贴墙让背景变干净的大色块。

## 2. 风光与城市

**核心思路：等光、找层次。**

- **时间**：黄金时刻 + 蓝调时刻为主战场，正午基本休息
- **层次**：好风光片 = 近景 + 中景 + 远景。缺前景就找一块石头、一丛草、一段栏杆补上
- **天空**：天空占比大时，等云——无云的天空是"白板"，有层次的天才值得入画
- **地平线**：放上下三分线，开网格线保证水平
- ** HDR/夜景模式**：大光比场景交给多帧合成，别手动硬救
- 雨后、雾天、雪后都是风光加成时刻，别宅着

## 3. 美食

**核心思路：光 + 角度 + 桌面干净。**

- **角度**：90° 俯拍表现摆盘阵列；45° 表现层次和体积；平拍适合饮品、汉堡类
- **光**：靠窗坐，用侧光；逆光拍饮品/汤类最通透（杯子会发光）。避免头顶灯光直射的油腻反光
- **构图**：桌面先"清场"，杂物移走；留白 + 一两件道具（手、餐具、杯子）做呼应
- **技巧**：动筷子前先拍；夹起一筷子、倒汤的瞬间比摆好的更馋人
- 白平衡偏黄时后期拉回，食物颜色要正才有食欲

## 4. 街拍

**核心思路：预判 + 决定性瞬间。**

- **焦段**：主摄（1x）最接近人眼视角，Story 感最强
- **拍法**：先找好背景（好看的墙、光影斑驳的路口），等人走进画面按快门——"守株待兔"比追着人拍成功率高
- **光线**：清晨傍晚的斜射光在建筑间拉出明暗分界，让人走在亮处
- **抓拍**：开连拍；EV 提前锁定；拍完不回放，继续观察
- **礼貌**：拍路人正面尽量微笑示意；不摆拍丑化、不传播造成困扰的照片

## 5. 夜景与灯光

- 蓝调时刻（日落后 20~40 分钟）拍城市：天是深蓝的，灯是亮的，一次快门两种颜色
- 夜景模式稳住 2~5 秒；车轨、光绘需要三脚架 + 专业模式（快门 4~30s，ISO 100）
- 找反光：雨后地面、水面、玻璃幕墙都能让画面翻倍
- 灯多的画面 EV 压暗，保住灯的色彩层次

## 6. 静物与产品（拍给二手平台也适用）

- **背景**：一张 A4 白纸/浅色桌布 + 靠窗侧光
- **补光**：对面立一张白纸/锡纸做反光板，压住暗部
- **角度**：45° 主视角 + 一张正面照 + 细节特写
- 手机贴近对焦主体，避免边缘畸变

## 7. 通用复盘法

每个题材拍完当天问自己：

1. 最好的一张好在哪？（光？构图？瞬间？）
2. 最差的一张差在哪？下次同一个场景怎么改？
3. 把答案写进 [作品复盘](../works/复盘模板.md)，下次拍摄前翻一遍

## 课后练习（选一个题材做完整流程）

1. 给朋友拍 9 宫格人像：含全景、半身、特写，全部窗光/黄金时刻
2. 黄金时刻拍一组城市风光，必须有前景、中景、远景三层
3. 一顿饭拍 5 张美食，俯拍/45°/逆光各至少一张
4. 街拍 30 分钟：找到一个好背景，等 3 个"人 + 光"的瞬间
