# 03 · 构图

> 目标：掌握一套够用的构图工具箱。构图的本质是**引导视线**——让观者第一眼看到你想让他看的东西。

## 1. 先建立三个意识

在背构图法之前，先记住这三条，它们比任何"法"都重要：

1. **做减法**：画面里每多一个元素，主体就弱一分。取景时主动排除干扰物
2. **有主体**：问自己"这张照片的主角是谁"。没有主体的照片，技巧再多也散
3. **制造关系**：主体和背景、前景之间要有呼应或对比（大小、明暗、颜色、远近）

## 2. 核心构图法（按使用频率排序）

### 2.1 三分法（九宫格）

把主体放在四条三分线的**交点**或线上，而不是死死居中。

- 地平线放在上或下三分线，**不要放正中间**
- 人像：眼睛落在上三分线附近
- 打开网格线，这招覆盖 80% 场景

### 2.2 居中构图

别迷信"三分法"，以下情况居中反而最有力量：

- 对称场景：建筑立面、倒影、走廊
- 单一主体特写：一朵花、一只猫、一个人正面看你

**要点：居中就必须严格居中**，歪 5% 就变成了失误。

### 2.3 引导线

用线条把视线"引"到主体上：

- 天然线条：道路、河流、栏杆、走廊、光带
- 斜线比水平线更有动感；汇聚线（如铁轨）纵深感最强

### 2.4 前景构图

主体前面加一层东西（树叶、窗框、人群、地面花纹），画面立刻有层次和"透气感"。

- 前景要**虚**或**暗**，不能比主体抢眼
- 贴近前景拍，虚化效果更明显

### 2.5 框架构图

用门窗、树枝、桥洞把主体"框"起来。框能天然聚焦视线，还能交代环境。

### 2.6 留白

主体只占画面一小部分，四周留出大面积干净空间（天空、白墙、海面）。

- 留白方向有讲究：人看向哪边，哪边多留
- 适合表达孤独、宁静、极简感

### 2.7 对比

把"不一样"放在一起：大人 vs 小孩、红色伞 vs 灰色街道、高楼 vs 小摊。对比产生故事感。

## 3. 视角与镜头语言

同一场景，换个角度等于换了一张照片：

| 视角 | 效果 | 适合 |
|---|---|---|
| 低角度（蹲/贴地） | 主体高大、天空更干净、遮挡地面杂物 | 人像、街拍、建筑 |
| 高角度（举高/俯拍） | 展示平面关系 | 美食、桌面、人群 |
| 平视 | 亲切、客观 | 记录、宠物视角（贴地拍猫狗） |
| 背影 | 留悬念、代入感强 | 旅拍、情绪片 |

**长焦压缩 vs 广角夸张：**

- 长焦（2x~5x）：空间被"压扁"，适合远拍街景人物、层次分明的大场景
- 超广角：空间被"拉伸"，贴近前景拍有冲击力，但人像慎用（脸会变形）

## 4. 常见构图错误自查

- [ ] 地平线歪了（开网格线 + 后期旋转修正）
- [ ] 顶天立地：头顶贴边、脚贴边，没有呼吸空间
- [ ] "切断"关节：构图裁在手腕、脚踝、膝盖上会很难受，裁在大小臂、大小腿之间更自然
- [ ] 背景长出"脑袋上的树/电线杆"（换个角度错开）
- [ ] 什么都想拍进画面，主体被淹没

## 5. 综合运用示例

拍一张朋友在古镇的照片，思考顺序：

1. 主体：人。背景：石板路 + 老墙
2. 选焦段：2x 长焦，压缩背景、避免游客入镜
3. 选构图：让小巷的透视线指向人物（引导线），人放在右三分线
4. 选视角：蹲下低角度，去掉地面杂物
5. 检查：头顶是否留白？边缘是否切脚？

## 课后练习

1. 同一主体用三分法和居中各拍一张，对比感觉差异
2. 找一条明显的引导线（走廊/道路），拍一张"线指向主体"的照片
3. 用前景拍一张：树叶/窗框做前景，主体在后
4. 拍一张"大面积留白"的极简照片
5. 翻出自己最近的 10 张照片，用第 4 节的自查清单找问题
